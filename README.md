# The AI School — HRM Portal

Internal workforce, onboarding, and daily operations portal for **The AI School**.

## Features

- **Role-Based Access Control**: Granular permissions (Intern, Team Lead, Manager, Core Team, HR, Finance, Super Admin).
- **Onboarding & Invitations**: Automated invitation flows, credential delivery, and profile setup.
- **Roster & Employee Directory**: Team structure, departments, shifts, project allocations, and manager hierarchies.
- **Daily Operations & My Day**: Check-in/check-out, slot-based work logs, attendance tracking, and End of Day (EOD) reporting.
- **Requests & Approvals**: Leave management, reimbursement claims, equipment requests, and shift adjustment workflows.
- **Reporting & Analytics**: Comprehensive exports, team timesheets, attendance summaries, and productivity insights.

## Tech Stack

- **Framework**: TanStack Start (React 19, TypeScript, SSR / Vite)
- **Styling**: Tailwind CSS, Radix UI primitives, Lucide Icons, Sonner
- **State & Data**: TanStack Query, Supabase (PostgreSQL, Auth, Storage)

## Getting Started

### Prerequisites

- Node.js (v20+) or Bun

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

### Build

```bash
# Production build
npm run build

# Preview production build
npm run preview
```
